# 📊 Dashboard de Análise de Vendas | Power BI

## Sobre o projeto

Projeto de Business Intelligence desenvolvido no Power BI com o objetivo de analisar o desempenho comercial de uma loja fictícia, permitindo acompanhar faturamento, lucratividade, desempenho de produtos e evolução das vendas ao longo do tempo.

## 🛠️ Tecnologias utilizadas

- Power BI
- Power Query
- DAX
- Excel

## 📈 Indicadores desenvolvidos

- Faturamento Total
- Lucro Bruto
- Ticket Médio
- Unidades Vendidas
- Top 10 Produtos por Quantidade Vendida
- Faturamento por Categoria
- Data da Última Atualização

## 📑 Estrutura do Dashboard

### 1. Visão Geral de Vendas

Visão consolidada dos principais indicadores de desempenho comercial.

### 2. Análise de Produtos

Análise de desempenho dos produtos e categorias, identificando os itens com maior volume de vendas.

### 3. Análise Temporal de Vendas

Acompanhamento da evolução das vendas ao longo do tempo, permitindo identificar tendências e variações de desempenho.

## 🎯 Objetivo

Desenvolver habilidades em análise de dados, modelagem, criação de indicadores e visualização de informações utilizando ferramentas de Business Intelligence.
